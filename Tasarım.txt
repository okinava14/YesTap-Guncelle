
Yemek Satış ve Takip Otomasyonu * YESTAP ***

Elektron motoru ve html paket olarak setup ve güncelleme özellikli paket program.

YesTap/

├── index.html
├── main.js            // Ana Electron süreci
├── package.json
├── package-lock.json
├── renderer.js
├── styles.css
├── build/             // Setup dosyalarının olduğu klasör
├── images/  	 	 	// Sistemde kullanılan (Banner) resimler ve ikon klasörü
├── node_modules/
└── data/              // Veri tabanı görevi gören JSON dosyaları
    ├── update/   	 	// İçinde güncelleme yapan yapı olacak klasör
    ├── GunlukListe/   // İçinde Pdf ve Excel dosyaları ekleyecek klasör  
    └── veriler/       // JSON dosyaları (Yemekler, Personeller vb.)
    	├── yemekfiyatlari.json     // Yemeklerin Grubu, Adı ve Fiyatlarının tutulduğu dosya
    	├── yemekmenu.json          // Bugünün Yemeklerinin tutulduğu dosya
    	├── personeller.json        // Personellerin Sicili ve Adı Soyadının tutulduğu dosya
    	├── gunlukadisyon.json      // Personellerin Seçtiği yemeklerin ve Adı Soyadının tutulduğu dosya
    	├── gunluksatislar.json     // Bugünün satışlarının tutulduğu liste dosyası
    	├── ayliksatislar.json      // İçinde bulunan (1-31) ayın satışlarının tutulduğu liste dosyası
   	    ├── aylikbilanco.json       // Son bir aylık yemek sayıları ve toplam tutarların tutulduğu liste dosyası
    	└── yillikbilanco.json       // Son bir yıllık yemek sayıları ve toplam tutarların tutulduğu liste dosyası
